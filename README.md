# Student Management System

A simple CRUD application built using Django.

## Features
- Add Student
- View Students
- Update Student
- Delete Student

## Technologies Used
- Python
- Django
- HTML
- Bootstrap
- SQLite

## How to Run

```bash
git clone https://github.com/teja-space/Student-Management-System.git

cd Student-Management-System

pip install -r requirements.txt

python manage.py runserver
```
